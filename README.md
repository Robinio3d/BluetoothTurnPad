# BluetoothTurnPad
This is a project where I built a 3d printed Bluetooth Arrow Keypad.
Check out the project on makerworld: https://makerworld.com/de/models/3524293-bluetooth-page-turner-pedal

Getting Started
  1. Download and install the Arduino IDE.

  2. Connect the ESP with an USB-C cable and select your board (ESP32 Dev Module) and the correct port on your computer.

  3. Open the sketch BLETurner.ino.

  4. Flash the code to your ESP32-WROOM-32.

  5. Check whether it starts pairing and establishing a Bluetooth connection

  6. Test arrow keys by shortly connecting GND with GPIO14/GPIO27
